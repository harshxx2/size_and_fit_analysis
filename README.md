# Size & Fit Analysis: PRD, Data Analysis, Dashboard & Prototype

## Overview
This repository showcases a full‑stack product case study for a **Size Recommendation Experience** on a fashion e‑commerce platform (Myntra). It demonstrates how raw fit‑feedback data can be turned into product insights, a PRD, an A/B test plan, a Tableau dashboard, and UI wireframes.

The pipeline is completely reproducible on a Windows machine (the current workspace). All code, data, and documentation live under the `myntra-size-fit-analysis/` directory.

## Quick‑Start Guide
### 1. Prerequisites
- **Operating System**: Windows 10/11 (the workspace is a Windows path).
- **Python**: 3.11 or newer (the `requirements.txt` pins exact versions).
- **Git** (optional) – to clone the repo.
- **Tableau Desktop/Public** – to render the dashboard.
- **Figma** (optional) – to view the UI wireframes (specs are in markdown).

### 2. Clone / Open the Project
```bash
# If you have git installed
git clone <repo‑url>  # replace with your remote URL or just copy the folder
cd "c:\Users\champ\Desktop\Myntra-size and fit analysis\myntra-size-fit-analysis"
```
If you are already in the workspace (as you are now), you can skip the `git clone` step.

### 3. Create a Virtual Environment & Install Dependencies
```powershell
# From the project root
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # PowerShell activation
pip install --upgrade pip
pip install -r requirements.txt
```
> **Note:** All packages are pure‑Python and install without network restrictions inside the sandbox. If you encounter any `EPERM` mkdir errors (rare on Windows), re‑run the `pip install` command once more – the sandbox will retry automatically.

### 4. Verify the Data
The raw JSON files are already present in `data/raw/`. To see a quick summary:
```powershell
python - <<PY
import pandas as pd
path = r"data/raw/renttherunway_final_data.json"
df = pd.read_json(path, lines=True)
print('Rows:', len(df))
print('Columns:', df.columns.tolist())
PY
```
You should see **192,544** rows, matching the numbers in `MASTER_PROJECT_PLAN.md`.

### 5. Run the Cleaning Pipeline (optional, already executed)
```powershell
python -m src.data_cleaning   # will read raw JSON and write cleaned CSV & SQLite DB
```
The script produces:
- `data/processed/renttherunway_cleaned.csv`
- `data/processed/fit_feedback.db`
- `data/processed/data_summary.json`
These files are already in the repository, so you can skip this step unless you want to reproduce the process.

### 6. Execute the Notebooks
Open any of the notebooks with Jupyter Lab / Notebook:
```powershell
jupyter notebook notebooks/01_data_understanding.ipynb
```
Run the cells sequentially. The notebooks will:
1. Load the raw data.
2. Apply cleaning (`02_data_cleaning.ipynb`).
3. Perform exploratory analysis (`03_exploratory_analysis.ipynb`).
4. Produce the final insight visualisations (`04_fit_insights.ipynb`).
All charts are saved automatically to `dashboard/charts/`.

### 7. Generate the Tableau CSVs (already done)
If you need to re‑run the aggregation script:
```powershell
python -m src.analysis   # writes dashboard_data.csv and the pre‑aggregated *.csv files
```
The script reads from the SQLite DB and writes the flat tables used by Tableau.

### 8. Open the Tableau Dashboard
1. Launch Tableau Desktop/Public.
2. **Connect → Text File** and select `dashboard/dashboard_data.csv`.
3. Follow the step‑by‑step instructions in `dashboard/tableau_instructions.md` to create the five core sheets and assemble the dashboard.
4. Export the dashboard as a PNG or PDF; the pre‑generated preview is `dashboard/dashboard_preview.png`.

### 9. Review the Product Documentation
All narrative artefacts live under `docs/`:
- `phase-1-product-framing.md` – problem framing & hypotheses.
- `prd.md` – complete Product Requirements Document.
- `metrics_framework.md` – HEART metric hierarchy.
- `ab_test_plan.md` – statistical power calculation & experiment design.
- `data_dictionary.md` – schema reference.
- `assumptions_and_limitations.md` – data‑source caveats.
- `interview_preparation.md` – elevator pitch, Q&A, and talking points.

### 10. View the UI Wireframes
The prototype specifications are markdown files in `prototype/`. They describe colours, layout grids, and interaction flows. The combined visual mock‑up is `prototype/prototype_preview.png`.

### 11. Run the Final Case Study
Open `case-study/final_case_study.md` – it ties together the problem, data insights, product solution, experiment plan, and impact metrics. It is ready to be added to a GitHub repository’s **README** or **Portfolio** section.

## Running End‑to‑End (one‑liner for copy‑pasting)
```powershell
# Activate env & run everything in order (assuming you are in the project root)
.\.venv\Scripts\Activate.ps1; \
python -m src.data_cleaning; \
python -m src.analysis; \
jupyter nbconvert --to notebook --execute notebooks/01_data_understanding.ipynb; \
jupyter nbconvert --to notebook --execute notebooks/02_data_cleaning.ipynb; \
jupyter nbconvert --to notebook --execute notebooks/03_exploratory_analysis.ipynb; \
jupyter nbconvert --to notebook --execute notebooks/04_fit_insights.ipynb
```
This will (re)run the data pipeline, generate all CSVs/charts, and render the notebooks as fully executed `.ipynb` files.
