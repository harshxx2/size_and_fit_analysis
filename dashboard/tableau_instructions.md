# Tableau Instructions

## Connecting the Data
1. Open Tableau Desktop (or Tableau Public).
2. Click **"Connect" → "Text File"** and browse to:
   `dashboard/dashboard_data.csv` in the project root.
3. Tableau will infer the schema. Verify that the **"Data Types"** match (e.g., `size` as *String*, `non_fit_rate` as *Number (decimal)*).

## Core Sheets (5)
| Sheet | Description | Key Fields | Suggested Marks |
|---|---|---|---|---|
| **Fit Breakdown** | Donut/Pie showing overall fit vs small vs large. | `fit` | Color, Angle |
| **Non‑Fit by Category** | Bar chart of non‑fit rate per category (filter to categories with ≥200 feedback entries). | `category`, `non_fit_rate` | Columns, Color |
| **Sizing Risk by Size Tier** | Horizontal bar of non‑fit rate per size tier (XS‑XXXL+). | `size_group`, `non_fit_rate` | Rows, Color |
| **Body‑Type Heatmap** | Matrix of body‑type vs fit outcome percentages. | `body_type`, `fit`, `count` | Rows, Columns, Color |
| **Category × Size Heatmap** | Cross‑tab of categories (rows) vs size groups (columns) coloured by non‑fit rate. | `category`, `size_group`, `non_fit_rate` | Rows, Columns, Color |

## Filters & Interactivity
- **Category Filter**: Quick filter on `category`.
- **Size Group Filter**: Quick filter on `size_group`.
- **Fit Filter**: Allows toggling between *fit*, *small*, *large*.
- Use **Dashboard Actions** to highlight corresponding rows in the heatmap when a bar is selected.

## Export & Sharing
- Export the dashboard as a **PDF** for the portfolio.
- Publish to **Tableau Public** (optional) and link in the README.

*All visualizations are based on the pre‑aggregated CSV files in `dashboard/` generated by the Python analysis scripts.*
